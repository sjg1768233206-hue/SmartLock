# SmartLock - 智能门锁系统

基于 RK3588 的智能门锁系统，支持人脸识别（NPU加速）、RFID刷卡、密码开锁、远程控制等多种开锁方式。

### 核心功能
- **人脸识别开锁** - 基于 RetinaFace + MobileFaceNet，NPU 加速
- **RFID 刷卡开锁** - 支持 RC522 模块，可添加/删除卡片
- **实时视频监控** - WebSocket 实时视频流传输
- **温湿度监测** - AHT20 传感器实时采集环境数据

### 安全功能
- **陌生人告警** - 连续检测到陌生人自动拍照并推送告警
- **开锁记录** - SQLite 数据库存储所有开锁记录
- **密码管理** - 支持管理员密码设置和验证
- **Web 管理界面** - 通过浏览器查看记录和管理设备

### 扩展功能
- **HTTP API** - RESTful API 接口，方便集成
- **WebSocket 通信** - 实时双向通信
- **远程管理** - 支持远程查看状态和开锁记录
