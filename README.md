# SmartLock - 智能门锁系统

基于 RK3588 的智能门锁系统，支持人脸识别（NPU加速）、RFID刷卡、密码开锁、远程控制等多种开锁方式。

## 功能特性

- 🔒 **多种开锁方式**
  - 人脸识别（OpenCV Haar Cascade 检测 + MobileFaceNet NPU 识别）
  - RFID刷卡（RC522）
  - 密码输入
  - 远程控制（WebSocket + HTTP）

- 👤 **人脸管理**
  - 人脸录入与特征提取
  - 人员管理（增删改查）
  - 陌生人连续5帧报警并拍照

- 📊 **数据记录**
  - 开门记录（时间、用户、方式、结果）
  - 告警记录
  - 今日开门次数统计

- 🌐 **远程控制**
  - WebSocket实时通信
  - HTTP服务器提供Web界面
  - 远程解锁/锁定/状态查询

- 📈 **传感器**
  - AHT20温湿度传感器
  - 实时显示环境数据
